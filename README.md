# Student Academic Performance & Career Path Predictor

A CLI-based Python application that predicts a student's final academic performance score, grade category, placement readiness level, and recommended career path using customized weighted algorithms.

## Features
- **Predictive Engine:** Evaluates performance based on attendance, study hours, coding assessment scores, and completed projects.
- **Career Path Recommendation:** Analyzes technical input parameters to suggest specialized tech domains.
- **Data Persistence:** Saves prediction records locally in a text-based storage file (`student_predictions.txt`).
- **Interactive CLI:** Easy-to-use menu interface for generating and viewing past predictions.

## Prerequisites
- Python 3.x installed on your system.
